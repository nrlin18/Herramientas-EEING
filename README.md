# Herramientas Eléctricas — EEING

App móvil de EEING · Energía e Ingeniería (Managua, Nicaragua): cálculos eléctricos, motores, transformadores, analizador de redes, CCTV, voz y datos y sistemas contra incendios.

**Abrir / instalar:** https://nrlin18.github.io/Herramientas-EEING/

En Android: abra el enlace en Chrome → **⬇ Instalar** (o menú ⋮ → Instalar aplicación). Funciona sin internet una vez instalada.
